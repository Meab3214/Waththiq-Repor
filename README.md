# وثّق — Waththiq Reports V3

تطبيق ويب/PWA عربي لإنشاء تقارير تعليمية بواجهة تفاعلية حديثة، مع معاينة مباشرة وتصدير PDF عبر الطباعة.

## الخصوصية
لا توجد قاعدة بيانات ولا حسابات مستخدمين. بيانات التقرير والصور تُعالج داخل جلسة المتصفح ولا تُرسل للتخزين.

## V3
- واجهة RTL متجاوبة للجوال والكمبيوتر.
- بيانات الجهة والتقرير والأهداف والتنفيذ والنتائج والتوصيات.
- مؤشرات وإحصائيات تلقائية.
- رفع حتى 15 شاهدًا مصورًا مع ترتيب ووصف.
- خمسة اتجاهات بصرية للتقرير.
- PWA ودعم العمل دون اتصال بعد التحميل الأول.
- تصدير/طباعة A4 مباشرة.

## النشر
المشروع Static ويمكن نشره مباشرة عبر GitHub Pages من فرع `main` وجذر المستودع.
